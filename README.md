## 🚀 Featured Projects

### [signal › over › noise](https://github.com/akatetron/signal-over-noise) · [live site](https://akatetron.github.io/signal-over-noise/)
[![Validate detections](https://github.com/akatetron/signal-over-noise/actions/workflows/validate-detections.yml/badge.svg)](https://github.com/akatetron/signal-over-noise/actions/workflows/validate-detections.yml)

My SOC analyst portfolio: **10 detection rules** (Sigma, KQL, SPL, Suricata) mapped to MITRE ATT&CK with false-positive and tuning notes, a **five-stage intrusion reconstruction** from Sysmon logs with a formal incident report, and **seven SIEM triage findings** with a documented disposition for each. Rules are validated automatically in CI.

### [ad-detection-lab](https://github.com/akatetron/ad-detection-lab)
[![detection-tests](https://github.com/akatetron/ad-detection-lab/actions/workflows/tests.yml/badge.svg)](https://github.com/akatetron/ad-detection-lab/actions/workflows/tests.yml)

Detection engineering for one **Active Directory attack chain** — credential theft → lateral movement. **Six Sigma rules** with Microsoft Sentinel **KQL** and Splunk **SPL** conversions, each mapped to MITRE ATT&CK, with an offline test harness in CI. Five of the six are **validated against real public attack telemetry** (OTRF Security-Datasets) — e.g. the LSASS rule fired on the Mimikatz access and stayed quiet on 271 other LSASS opens in the same capture.
